## Evidence meanings

- **Implemented**: the integration source/delivery contains the path.
- **Tested**: automated checks exercise the stated contract or resource.
- **Browser-inspected**: the live console was operated and viewed for the named
  scenario. It is not a pixel or timing comparison.
- **Native-compared**: a specific Azahar/native capture or executed source
  fixture was compared. Evidence is limited to the recorded region/state.
- **Incomplete**: a known adaptation, missing source, unsupported format or
  unverified route remains.

## Acceptance status

The scoped system is substantially implemented and provenance-backed. Final
acceptance is still open, and strict 1:1 fidelity is unproven for every area.
The gaps are:

- No whole-screen matched native comparison of pixels, motion, audio and input
  timing exists for any screen.
- Game Notes' initial Double mode and switch sequence are source-traced and
  integrated ([audit](native-notes-switch-source-audit.md)); its transitions,
  sounds and title panel remain unimplemented, and its delivered screen has
  no matched native comparison.
- The parental notice has not had a matched native LCD/timing comparison.
- amiibo header/`PortalBtnSub` materials and the NNID unsigned-in body are missing.
- Sound playback is unproven without supplied songs.
- The hardware model is not visually accepted.

The [feature map](feature-map.md) assigns each gap. The closing check is one
versioned scenario matrix in the browser and a verified isolated Azahar profile. It
should record LCD pairs, the input sequence, animation/audio timestamps and
intentional portfolio differences.

An Azahar launch on this machine unexpectedly wrote emulator runtime state to
the default macOS profile despite an isolated path supplied to the process.
No capture from that session is accepted as native comparison evidence. Do
not launch native sessions from the installed app or rely on a shell working
directory override. The repository and delivered website were not affected
by those emulator profile writes. A subsequent
[guarded copied-bundle launch](native-reference-profile-isolation.md) did
isolate its profile and opened the native Settings main page, but coordinate
input could not reliably reach subpages; it is a smoke check, not an accepted
native comparison.
