# Download size and device optimisation — 29 September 2026

Branch `dev-size-opt`, stacked on `dev-lag-fix`
([performance note](performance-2026-09-28.md)). "Before" is the
`dev-lag-fix` head, built and served the same way as "after".

## What a visit downloaded

`scripts/perf/network.mjs` records every response of a scripted visit: load,
opening, then opening About and Settings. Measured before these changes:

| Resource | Transfer | Loaded |
| --- | ---: | --- |
| Console model `joshua-xl.glb` (gzip) | 10.0 MB | startup |
| Images (native textures, font sheets, portfolio photos) | 2.8 MB, 213 requests | startup |
| Native sound effects (WAV) | 1.2 MB | after the model; not awaited |
| JSON (native packs, manifests, banner models) | 0.57 MB (4.7 MB decoded) | startup |
| JavaScript | 0.47 MB | startup |
| **Total** | **15.45 MB** | |

The model's 12.4 MB was 4.3 MB of WebP textures and about 7.5 MB of meshopt
geometry (640k triangles, float attributes).

## Changes

1. **Repacked model** (`scripts/pack-model.mjs`, `gltfpack@1.3.0`). The sourced
   `joshua-xl.glb` is unchanged and remains the reference for the layout tests
   and the source preview. The derived model keeps the following as float:
   positions, UVs and normals. It also keeps node names, the hierarchy,
   transforms, materials, metadata extras and texture images byte-for-byte.
   Mesh names are restored from the source. Tangents become 8-bit normalised
   (gltfpack's limit), and duplicate texture records merge. Size: 12.4 → 7.5 MB
   (gzip 10.4 → 6.0 MB).
2. **Compact model for phones:** the packed model with the eleven 4096 px
   textures halved to 2048 px (`scripts/limit-glb-textures.mjs`; lossless
   sources stay lossless, lossy ones are re-encoded at WebP q92). It is chosen
   when the largest drawing buffer the *screen* can produce is at most 1700
   device px (`prefersCompactModel`). That covers every phone at the render
   pixel-ratio caps, but not laptops, desktops or tablets. At that size the
   GPU never samples the 4096 px level. Size: 5.5 MB (gzip 4.1 MB). GPU texture
   memory falls by about 0.7 GB.
3. **Content-hashed, immutable models:** both files are named by content hash
   and served with `Cache-Control: public, max-age=31536000, immutable`.
   `src/scene/model-delivery.ts` is generated, and a test fails if it is stale.
4. **Portfolio photos no longer gate the first frame.** Only the HOME icons are
   awaited. The photos (960×1200 to 2000×1500, ~1 MB) keep downloading in the
   background at full resolution. While one is still loading, its screen shows
   the app icon, and "Image unavailable" is reserved for real failures.

## Deliberately unchanged

- **Native firmware assets** (packs, textures, font sheets, WAV cues): the
  manifest records each delivered file's SHA-256 and size as provenance, so
  lossless recompression would still break the recorded identity. This belongs
  to the Assets lane.
- **`public/models/silver-3ds-xl.glb` (7.7 MB):** not fetched by the site, but
  read by `tests/model.test.mjs` and the export scripts.
- **JavaScript (0.5 MB gzip):** about 4% of a visit; splitting stock apps would
  be invasive.
- **Brotli:** `next start` serves gzip only. A host that serves Brotli would
  bring the packed model to 5.8 MB and the compact one to 3.9 MB.

## Fidelity

Screenshots of the served builds (reduced motion, identical clock) differ as
follows.

| Screenshot | Pixels differing | ≤ 2 levels | > 32 levels |
| --- | ---: | ---: | ---: |
| Desktop HOME, 2880×1800 | 4.6 % | 96 % of those | 252 px |
| Desktop rotated | 3.8 % | 98 % of those | 265 px |
| Mobile HOME, 1170×2532 (compact) | 5.2 % | 97 % of those | 52 px |
| Mobile rotated (compact) | 2.6 % | 98 % of those | 88 px |

- **Where the differences are:** the ≤ 2-level differences come from the
  8-bit tangents in normal-mapped shading. The > 32-level pixels are
  anti-aliased silhouette samples along the lid edge. Crops are
  indistinguishable by eye.
- **Compact threshold:** at the 1600 px edge case (1600×1000 @1x), the compact
  model adds ±1–2-level differences on a further 3.8 % of pixels over the
  packed one.
- **Controls:** mouse hits on A, HOME and the D-pad, press travel, and
  projected control positions are identical to the source model.

This is a labelled delivery adaptation of the sourced model, not a change to
it. Rerun `scripts/pack-model.mjs` after any re-export; `model-delivery.test`
enforces this.
