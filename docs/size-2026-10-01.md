# Download size without fidelity loss — 1 October 2026

Branch `dev-size-opt` (PR #3), reworked on top of `main` after the render
scheduling PR #2 merged. "Before" is `main` (`8e9d085`), built and served the
same way as "after".

The first version of this branch (29 September) traded detail for bytes: it
quantised tangents to 8 bits, served phones a model with its 4096 px textures
halved, and, without `-kv`, dropped UVs and tangents from meshes whose glTF
material had no texture (the VGPU paint surface later samples those UVs). It
changed 2.6–5.2 % of screenshot pixels. That version is withdrawn. This
version keeps every texture, every vertex attribute and every vertex value.

## What a visit downloaded

`scripts/perf/network.mjs` records every response of a scripted visit (load,
opening, About and Settings). On `main` the 12.4 MB model was 10.0 MB of a
15.45 MB visit: 4.5 MB of WebP textures and 7.7 MB of meshopt geometry
(640,545 triangles, float attributes stored with the exponential filter).

## Changes

1. **Lossless model repack** (`scripts/pack-model.mjs`). The sourced
   `joshua-xl.glb` is unchanged; it remains the reference for the layout tests
   and `/source-preview`.
   - `gltfpack@1.3.0 -noq -cc -kn -km -ke -kv`: no quantisation, all vertex
     attributes kept, identical vertices merged, triangles reordered for the
     vertex cache. Node, mesh and material names, extras and images are kept
     (mesh names restored by `scripts/restore-glb-names.mjs`).
   - `scripts/meshopt-exp-lossless.mjs` then re-encodes each float stream with
     the exponential filter and meshopt's v1 codec at the smallest mode and bit
     count whose decode, through Three.js's own `MeshoptDecoder`, equals the
     input bytes. A stream with no exact encoding would stay unfiltered.
   - Result: 12.4 → 9.0 MB (gzip transfer 10.0 → 6.8 MB).
2. **Content-hashed, immutable model:** the file name carries its content hash
   and is served with `Cache-Control: public, max-age=31536000, immutable`.
   `src/scene/model-delivery.ts` is generated.
3. **Portfolio photos no longer gate the first frame.** Only HOME icons are
   awaited; the ~1 MB of photos load in the background at full resolution.
   While one is loading its screen shows the app icon; "Image unavailable" is
   reserved for real failures.

`tests/model-delivery.test.mjs` decodes both GLBs and proves, per node and
primitive, that the packed model draws the same multiset of triangles as the
source with bit-identical vertex records (all attributes) and the same
winding. It also checks byte-identical images, the scene contract (hierarchy,
transforms, materials, extras) and that the generated URL matches the source.

## Fidelity

`scripts/perf/screenshot-compare.mjs` captures `/source-preview` (sourced GLB)
and `/` (packed GLB) from the same production build in fresh headed Chromium
profiles: reduced motion, frozen clock, then optionally one scripted
hover-press-drag-hold-release. Control runs of a page against itself are
pixel-identical (0 differing pixels, desktop and iPad, both views).
[Report](perf/2026-10-01/size/screenshot-report.json).

| Screenshot | Differing pixels | Max delta | > 32 levels |
| --- | ---: | ---: | ---: |
| Desktop HOME, 2880×1800 | 221 (0.0043 %) | 29 | 0 |
| Desktop rotated | 107 (0.0021 %) | 13 | 0 |
| iPad HOME, 2360×1640 | 193 (0.0050 %) | 15 | 0 |
| iPad rotated | 64 (0.0017 %) | 12 | 0 |
| Mobile HOME, 1170×2532 | 74 (0.0025 %) | 16 | 0 |
| Mobile rotated | 4 (0.0001 %) | 1 | 0 |

The residual pixels are isolated single samples along shell triangle edges.
The triangles and values are identical, so these are rasterisation tie-breaks
from the new draw order (coincident edges and depth ties), not lost detail.
Keeping the source triangle order removes them but saves only 0.34 MB, so the
reorder is kept and labelled here. Projected control positions after a drag
match the source model to 1e-7 px. Rerun `scripts/pack-model.mjs` after any
re-export; `model-delivery.test` enforces this.

## Deliberately unchanged

- **Native firmware assets:** the manifest records each delivered file's
  SHA-256 and size as provenance (Assets lane).
- **Textures:** byte-identical; no resizing or re-encoding.
- **`public/models/silver-3ds-xl.glb`:** not fetched by the site.
- **Brotli:** `next start` serves gzip only.
