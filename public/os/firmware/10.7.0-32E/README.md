Its CIA SHA-256 is `2863c6c4e7b1c79e4352b63cde72994fa9c3b8bdd8dfd2afd4dd4104636b1898`. Installed Azahar HOME, CVer and NVer payloads match the supplied packages byte-for-byte.

`manifest.json` records the original title/version/hash, converted resource sizes and hashes, source paths, available packs and unconverted resources. PNGs retain source texture pixels; fonts retain native mappings/bearings/advances and are repacked without resampling. JSON carries native layouts, materials, animation keys and English messages. Every relative URL resolves against the manifest URL, including URLs within packs.

Only converted visual/message resources are included here. Source CIAs, executables, keys, certificates, shaders and user saves remain outside public output. The original ROMFS/ExeFS extraction and test evidence reside on the user's SanDisk artifact volume. AR Games and Face Raiders are excluded.

Nintendo/Fontworks ownership is retained. These assets do not inherit the website source licence. This conversion does not establish pixel-identical rendering or behavioural fidelity; unsupported fields and containers remain recorded.
